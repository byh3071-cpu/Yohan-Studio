# Birthday × Usagi 공개·Instagram 리서치

- 최종 확인: 2026-08-03
- 상태: 진행 중
- 사용 원칙: 공식 문서 우선. 공식 문서끼리 충돌하거나 실제 앱 상태가 다르면 발행 직전 실기 확인을 우선한다.

## 1. Instagram 공식 확인

### Insights와 게시 시간

공식 Instagram 도움말은 비즈니스·크리에이터 계정에서 Insights를 무료로 제공한다고 설명한다. 게시물과 Reel의 조회·도달·상호작용을 확인할 수 있고, 팔로워가 100명 이상이면 팔로워가 가장 활발한 시간도 제공한다.

출처:

- [About Instagram Insights](https://www.facebook.com/help/instagram/788388387972460)

캠페인 적용:

- 모든 계정에 통하는 “조회수 터지는 시간”을 고정 규칙으로 만들지 않는다.
- 새 계정은 동일한 품질의 콘텐츠를 서로 다른 시간대에 순차 게시해 기준선을 만든다.
- 팔로워 100명 이후에는 일반 추천 시간보다 계정 Insights의 활성 시간을 우선한다.
- 게시 시간보다 콘텐츠 훅·완주·저장·공유·프로필 방문을 함께 측정한다.

### Reel 형식

공식 도움말에서 확인된 값:

- 업로드 허용 비율: 1.91:1~9:16
- 최소 프레임률: 30 FPS
- 최소 해상도: 720px
- 커버 권장: 420×654, 1:1.55
- 앱 설정에서 최고 품질 업로드를 켤 수 있음
- Reel은 최대 20분까지 녹화할 수 있으나 3분을 넘으면 신규 사용자에게 추천되지 않는다고 안내

출처:

- [Reel size and aspect ratios](https://www.facebook.com/help/instagram/1038071743007909)
- [Record a reel on Instagram](https://www.facebook.com/help/instagram/225190788256708)

캠페인 적용:

- 첫 두 편은 15~30초를 목표로 하되, 장면을 억지로 줄여 이해가 깨지면 45초까지 허용한다.
- 촬영 마스터는 9:16 세로로 잡고, 중요한 텍스트와 피사체는 화면 중앙에 둔다.
- 커버는 업로드 전에 별도 확인한다. 공식 도움말상 업로드 후 커버 편집 제한이 있을 수 있다.
- 촬영·편집 후 최고 품질 업로드 설정을 확인한다.

### 사진·Carousel 형식

공식 사진 도움말은 폭 1080px까지 유지하며 지원 비율을 1.91:1~3:4로 안내한다. 세로 최대 예시는 1080×1440이다. 공식 Carousel 도움말 검색 결과는 최대 10개를 안내하지만, 기존 내부 스펙은 20개를 적고 있어 서로 일치하지 않는다.

출처:

- [Image resolution of photos you share](https://www.facebook.com/help/instagram/1631821640426723)
- [Share a post with multiple photos or videos](https://www.facebook.com/help/instagram/269314186824048)

캠페인 적용:

- 장수는 성과를 위해 7~10장으로 설계하므로 현재 충돌이 초안 제작을 막지는 않는다.
- 최종 템플릿 비율은 디자인 시작 직전에 실제 앱 업로드 화면으로 3:4와 4:5 크롭을 비교해 확정한다.
- 한 Carousel 안에서는 모든 자산의 방향을 같게 맞춘다.
- 기존 `instagram-carousel.md`의 `verified: 2026-07-04`, “Meta 원문 미확보” 값은 최신 공식 확인으로 갱신할 후속 작업이다.

### 음원과 광고 확장 가능성

공식 Boost 도움말은 9:16, 90초 미만을 요구하며 저작권 음악이 들어간 Reel은 Boost할 수 없다고 안내한다. 당장 광고를 집행하지 않더라도 나중에 잘된 Reel을 광고로 확장할 수 있게 하려면 자체 오디오나 사용 권리가 명확한 음원을 쓰는 편이 안전하다.

출처:

- [How to boost Instagram Reels](https://www.facebook.com/help/instagram/570215404599013)

캠페인 적용:

- 개인용 앱에 넣은 BGM을 Reel에 자동 재사용하지 않는다.
- 현장 소리·자체 효과음·상업 사용 가능한 음원을 우선한다.
- 광고 집행은 별도 사용자 승인 항목으로 유지한다.

## 2. 우사기·치이카와 권리 확인

공식 운영 주체와 공식 사이트는 확인했지만, 이번 검색에서는 원본·파생 이미지나 캐릭터 상품형 파일의 공개 배포를 허용하는 공식 2차 창작 가이드를 찾지 못했다.

확인한 공식 출처:

- [치이카와 공식 사이트](https://chiikawa-info.jp/)
- [Gray Parker Service](https://grayparkaservice.com/)

판정:

- 공식 허용 문서가 확인되지 않았다는 사실은 사용 허가를 의미하지 않는다.
- 우사기 이미지·CUR·ANI·ICO·ZIP은 계속 `BLOCK`으로 유지한다.
- 포트폴리오·Reel의 짧은 화면 표시도 자동 허용으로 간주하지 않고 발행 전 별도 검토한다.
- 범용 Windows 테마 도구 공개판에는 우사기 형상과 명칭을 넣지 않는다.

## 3. 쇼룸 사례 전달 기준

### 결과와 Why를 먼저 보여주는 이유

Nielsen Norman Group의 웹 읽기 연구는 사용자가 긴 본문을 정독한다고 가정하지 말고, 가장 중요한 내용을 첫 두 문단에 두며 정보가 담긴 제목·소제목과 시각적 그룹을 사용하라고 권한다. 포트폴리오 사례 가이드도 최소한 프로젝트 개요, 본인 역할, 과정, 결과와 영향, 배운 점을 보여줘야 한다고 정리한다.

출처:

- [F-Shaped Pattern of Reading on the Web](https://www.nngroup.com/articles/f-shaped-pattern-reading-web-content/)
- [Creating a UX Design Portfolio Case Study](https://www.youtube.com/watch?v=jt1WroGHvBs)
- [7 Portfolio Mistakes That Could Hurt Your UX Job Search](https://www.nngroup.com/articles/?asset=publications&page=22)

캠페인 적용:

- 쇼룸 첫 화면에서 최종 결과, 한 문장 Why, 역할과 상태를 먼저 보여준다.
- 상세는 결과와 실제 증거 → 왜 만들었는지 → 방향을 바꾼 실패 → 선택 이유와 대안 → 검증 → 책임과 한계 순으로 구성한다.
- 날짜순 일지는 쓰지 않는다. 날짜는 최신 프로젝트 정렬과 사례 안의 3~4개 전환점 타임라인에만 쓴다.
- 제목과 소제목의 첫 단어에 정보가 담기게 한다. ‘배경’보다 ‘왜 이미지 생성을 멈췄나’, ‘과정’보다 ‘원복해도 우사기가 남았다’처럼 쓴다.
- 수치는 많을수록 좋은 것이 아니다. 결과를 설명하는 수치만 첫 화면에 올리고, 테스트 개수처럼 집계가 흔들리는 값은 재검증 전까지 뺀다.

### 이미지가 맡을 정보부터 정한다

W3C WAI는 informative 이미지의 대체 텍스트가 단순한 외형 묘사가 아니라 이미지가 전달하는 의미를 담아야 한다고 설명한다. 중요한 텍스트를 이미지 안에만 넣지 말고, 본문이나 적절한 대체 텍스트로도 제공해야 한다.

출처:

- [W3C WAI Images Tutorial](https://www.w3.org/WAI/tutorials/images/)
- [Informative Images](https://www.w3.org/WAI/tutorials/images/informative/)

캠페인 적용:

- 이미지마다 결과 증명, 맥락 설명, 실패 비교, 구조 설명 중 하나의 역할만 정한다.
- 실물 영상이나 실제 사용 사진은 결과 증거로 사용하고, 생성 이미지는 비어 있는 분위기 컷을 보완할 때만 사용한다.
- 이미지의 핵심 의미는 인접 문장에서도 이해할 수 있게 한다.
- 쇼룸의 imageAlt는 ‘노트북 사진’ 같은 외형이 아니라 ‘14장 생일 앱이 마지막 선물 장까지 실행된 화면’처럼 증거의 의미를 적는다.

## 4. 현재 내부 문서와의 차이

| 항목 | 기존 내부 스펙 | 2026-08-03 확인 | 조치 |
|---|---|---|---|
| Carousel 비율 | 4:5 우선, Meta 원문 미확보 | 공식 사진 도움말은 3:4까지 지원 | 실기 비교 후 전역 스펙 갱신 |

| Reel 제작 | 기존 스펙은 대본만 | 사용자는 촬영·편집 초보 워크플로도 필요 | 캠페인 촬영·편집 체크리스트 별도 작성 |

## 5. 아직 확인할 것

- Instagram 앱 안의 실제 Carousel 최대 장수와 3:4 크롭 결과

- Birthday 앱 E2E 정의 수와 실제 실행 결과의 최신 집계
- 우사기 친구 노트북의 Windows 버전과 지속 사용 항목 — 해당 내용을 글에 쓸 때만 추가 확인
