# Luna × Max 카드뉴스 생성 기록

## 결과물 역할

- 채널: Instagram 카드뉴스
- 계정: `@yohanstudio_ai`
- 매체 규격: 1080×1350 PNG 8장
- 상태: 시각 승인 뒤 내용 정확성 결함이 발견되어 폐기됨
- 폐기 사유: 기존 카드의 `codex -e max` 안내에서 `-e`를 추론 강도 옵션으로 잘못 해석함
- 후속 상태: 교정된 v2 작업본을 재검증 중이며 아직 승인본으로 보관하지 않음
- 용어 기준:
  - Luna: 구현 작업 모델
  - Max: Luna에 적용하는 추론 강도
  - Luna 작업 경로: Sol이 Luna 작업 스레드로 일을 보내는 방식

## 생성 비주얼

### 1. 마스터 궤도

짙은 흑연색 배경 위에 보랏빛 초승달, 세 개의 궤도, 금속성 작업 노드, 따뜻한 백색 연결선을 배치했다. 상단에는 한글 제목을 후편집할 수 있도록 여백을 남겼고 이미지 생성 단계에서는 문자를 넣지 않았다.

### 2. 작업 경로

하나의 지휘 흐름이 세 개의 병렬 작업 경로로 나뉜 뒤 보랏빛 결과로 다시 합쳐지는 구도를 사용했다. 구현 위임과 검토 회귀를 시각적으로 표현했다.

### 3. Max 추론 링

초승달을 중심으로 동심원을 확장해 추론 강도를 표현했다. 속도나 화려함보다 신중한 심화 추론이 느껴지도록 절제된 조명과 재료를 사용했다.

## 조판 결정

- 생성 이미지에는 한글·명령어를 넣지 않고 Noto Sans KR 기반으로 후편집했다.
- 보라색은 큰 면보다 핵심 단어·강조선·작은 상태 배지에 사용했다.
- 정보 패널과 중심 비주얼이 겹치지 않도록 최종 v3에서 분할 구도로 수정했다.
- `LUNA / MAX` 표기는 둘 중 하나 또는 두 모델로 오해할 수 있어 제거했다.
- `lane`은 처음 보는 사람에게 설명되지 않은 내부 용어이므로 본문에서는 `Luna 작업 경로`로 풀어 쓰고, 실제 승인 문장에만 `task lane`을 유지했다.

## 재사용 가능한 부분

- 근흑색 에디토리얼 배경과 보랏빛 달 포인트
- 따뜻한 백색 궤도로 역할 관계를 나타내는 방식
- 이미지 생성과 정확한 타이포 조판을 분리하는 제작 방식
- 76px 외곽 여백, 얇은 패널 테두리, 하단 계정·페이지 번호 시스템

## 반복하지 않을 부분

- 패널로 달이나 핵심 궤도를 가리는 구성
- 큰 보라색 CTA 면으로 화면을 압도하는 구성
- 모델과 추론 강도를 `/`로 묶는 표기
- 설명 없이 `lane`을 노출하는 문구
