## V3 사실 교정

- Sol Advisor는 특정 계정 전용이 아니며, 요구 조건을 충족한 다른 사용자도 사용할 수 있다고 명시했습니다.
- Luna/Max 스모크 테스트에서 설정 `ready`, 구성 `valid: true`, 필수 앱 작업 도구 6개, `create → wait → read`, 실제 `gpt-5.6-luna / max`, `SMOKE_LUNA_MAX_OK`를 확인했습니다.
- 현재 장기 채팅에서 `wait_threads`가 누락됐던 현상은 새 채팅에서는 재현되지 않았습니다. 앱 코드에는 도구 구현이 있었고 새 채팅에서 정상 노출됐으므로, 플러그인의 범용 기능 결함이 아니라 기존 채팅의 도구 목록 스냅샷 문제로 분리했습니다.
- Windows 원본 `main`에는 Bun의 POSIX 모드 투영 때문에 비공개 `PLUGIN_DATA`를 거부하는 호환 오류가 남아 있습니다. 이슈 #20과 수정 PR #22가 2026-08-14 기준 모두 열려 있음을 반영했습니다.
- 수정은 Windows ACL 보안 경계를 다루는 호환 패치입니다. upstream 병합 전에는 원본 설치 명령이 Windows 전체에서 무조건 작동한다고 표현하지 않습니다.

## V3 문체·CTA 교정

- 카드 7을 “타 사용자 사용 가능 → 필수 권한 → Windows 반영 확인” 순서로 바꿨습니다.
- 기존 채팅의 도구 스냅샷 문제는 카드 핵심 흐름을 방해하지 않도록 후속 DM의 문제 해결 절차로 옮겼습니다.
- 캡션에는 타 사용자 사용 가능성과 Windows 확인 필요를 함께 밝혀 과장과 불필요한 베타 낙인을 모두 피했습니다.
