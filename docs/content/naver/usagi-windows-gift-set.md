# 릴스에서 본 우사기 커서, 직접 Windows 선물 세트로 만들었다

- 비전공자가 AI와 함께 만들고 직접 검증한 기록입니다. -

> **한눈에 요약**
> 친구가 좋아하던 우사기 커서 릴스를 보고 Windows 선물 세트를 직접 만들었다.
> 커서·휴지통·폴더·작업 표시줄까지 묶었지만, 반복 적용 뒤에는 원복을 눌러도 우사기가 남았다.
> 설치 성공이 아니라 원래 상태로 정확히 돌아가는 것을 완료 기준으로 다시 잡았다.

친구가 우사기 커서 릴스를 보고 좋아했다. 그걸 보면서 나도 만들 수 있지 않을까 생각했고, 실제로 Windows 선물 세트로 만들었다.

이 글은 예쁜 아이콘을 잘 만든 이야기가 아니다. 가장 크게 막힌 곳은 설치가 아니라 되돌리기였다.

## 💡 커서 하나가 세트가 되기까지

시작할 때 목표는 커서 하나였다. 그런데 실제로 선물하려니 커서만 바꿔서는 한 세트로 보이지 않았다.

휴지통과 폴더, 작업 표시줄까지 같은 분위기로 이어져야 했다. 최종 출력 파일은 22개가 됐다. 테마 22종이라는 뜻이 아니라, 한 세트를 구성하는 파일을 전부 센 숫자다.

[이미지 삽입: 한 세트를 구성하는 파일 22개의 구조 — 커서 2개, 대기 애니메이션 1개, 휴지통 12개, 폴더 6개, 작업 표시줄 1개 | https://yohanstudio.co/images/blog/usagi-windows-gift-set/output-files-22.png]

Windows는 커서와 아이콘마다 읽을 수 있는 파일 형식이 따로 있다. 커서는 CUR, 움직이는 대기 표시는 ANI, 휴지통과 폴더 아이콘은 ICO를 쓴다.

PNG 그림을 준비하는 것과 Windows가 실제로 읽는 파일을 만드는 것은 다른 작업이었다. 그래서 이름만 맞는지 보는 데서 끝내지 않고, 만들어진 파일이 실제로 로드되는지까지 검사했다.

## 🐛 원복을 눌렀는데 우사기가 남았다

가장 큰 실패는 설치가 아니라 복구에서 나왔다.

처음 적용할 때는 기존 설정을 백업하고 새 테마를 넣었다. 문제는 같은 설치를 다시 실행했을 때였다. 두 번째 적용이 현재 상태를 새 백업으로 덮었는데, 그때 현재 상태는 이미 우사기였다.

이후 원복을 실행하면 프로그램은 자기가 가진 백업을 충실히 돌려줬다. 그 백업 자체가 오염돼 있었을 뿐이다.

해결은 최초의 깨끗한 상태를 한 번만 보존하고 절대 덮지 않는 것이었다. 처음 적용하기 전의 Windows 상태가 이미 있으면, 재적용 과정에서 새 백업으로 교체하지 않게 했다.

[이미지 삽입: 적용할 때마다 백업을 덮어써 꾸민 흔적이 남는 실패 경로와, 최초 상태를 한 번만 보존해 정확히 되돌리는 해결 경로 | https://yohanstudio.co/images/blog/usagi-windows-gift-set/pristine-backup-flow.png]

## ✅ 되돌린 뒤에 아무것도 남지 않아야 완료다

적용과 원복을 격리한 Windows 환경에서 반복해 확인했다. 예쁜 결과를 다시 만드는 검사와, 원래 상태로 정확히 되돌리는 검사를 따로 뒀다.

아래는 같은 화면을 두 번 찍은 것이다. 왼쪽은 커서·휴지통·폴더가 한 세트로 바뀐 상태, 오른쪽은 전체 원복 뒤다. 설정값과 설정 파일이 모두 적용 전과 같아졌다.

커서는 화면 캡처에 찍히지 않아, 그때 적용돼 있던 커서 파일을 같은 자리에 겹쳐 표시했다.

[이미지 삽입: 커서·휴지통·폴더를 함께 적용한 화면과 전체 원복한 화면 대조 | https://yohanstudio.co/images/blog/usagi-windows-gift-set/apply-restore.png]

[여기 네 말: 원복을 눌렀는데 우사기가 그대로 있는 걸 처음 봤을 때 심정이 어땠는지 한두 문장]

## 🛡️ 우사기 파일은 공개하지 않는다

이번 세트는 친구에게 준 개인 선물이다. 우사기 이미지와 커서·아이콘 파일, 설치 압축 파일, 저장소는 공개하지 않는다.

캐릭터를 개인적으로 쓴 것과, 다른 사람이 내려받아 쓰도록 배포하는 것은 범위가 다르기 때문이다. 화면에 보이는 것과 원본 파일을 내려받게 하는 것은 분리했다.

나중에 공개할 수 있는 건 우사기 세트가 아니라 Windows 캐릭터 테마 빌더다. 직접 만들었거나 권리가 있는 이미지를 넣으면 커서와 아이콘을 만들고, 적용 전 상태를 백업하고, 언제든 전체 원복할 수 있게 하는 범용 도구다.

릴스에서 본 건 작은 커서 하나였다. 만들고 나니 선물의 완성은 커서가 움직이는 순간이 아니었다. 마음이 바뀌면 처음 상태로 정확히 돌아갈 수 있는 순간이었다.

개발자가 아닌 사람이 AI와 함께 만드는 과정을 기록하고 있습니다.
부족한 부분도 많지만, 하나씩 만들어가며 남기려고 합니다.
