# 릴스에서 본 우사기 커서, 직접 Windows 선물 세트로 만들었다

- 비전공자가 AI와 함께 만들고 직접 검증한 기록입니다. -

친구가 우사기 커서 릴스를 보고 좋아했다. 그걸 옆에서 보다가 생각했다. 저거 내가 만들어서 주면 되는 거 아닌가.

그렇게 시작했는데, 커서 하나로 끝나지 않았다. 결국 휴지통도 폴더도 작업 표시줄까지 다 우사기가 됐다.

그리고 다 만들고 나서 제일 크게 놀란 건, 예쁘게 만드는 것보다 **원래대로 되돌리는 게 훨씬 어려웠다**는 거였다.

## 💡 커서 하나만 바꾸니까 오히려 어색했다

처음엔 마우스 화살표만 바꾸면 되는 줄 알았다.

그런데 막상 적용해놓고 보니 이상했다. 커서만 우사기고 나머지는 그대로라, 귀여운 게 아니라 그냥 튀었다. 한 세트로 보이려면 눈에 들어오는 것들을 같이 맞춰야 했다.

그래서 휴지통을 넣었다. 비었을 때랑 꽉 찼을 때가 다르게 보여야 해서 두 종류가 필요했다. 폴더도 넣었는데, 귀가 있는 게 나은지 없는 게 나은지 정하기 어려워서 둘 다 만들었다. 마지막엔 작업 표시줄 아이콘까지 맞췄다.

기다릴 때 빙글빙글 도는 표시도 우사기가 걸어가는 걸로 바꿨다. 이건 만들면서 제일 재밌었던 부분이다.

## 🐛 원복을 눌렀는데 우사기가 그대로 있었다

여기서부터가 진짜 문제였다.

선물이니까 당연히 "싫으면 원래대로 돌리기" 버튼이 있어야 한다고 생각했다. 만들어뒀고, 잘 되는 것도 확인했다.

그런데 우연히 두 번 적용해본 다음에 원복을 눌렀더니, 우사기가 그대로 남아 있었다.

이유는 좀 어이없었다. 처음 적용할 때 "원래 상태"를 저장해두는데, 두 번째로 적용할 때 그 저장본을 **지금 상태로 다시 덮어쓰고** 있었다. 그때 지금 상태는 이미 우사기였다.

그러니까 원복 버튼은 제대로 동작한 게 맞다. 돌아갈 곳이 우사기였을 뿐이다.

[이미지 삽입: 적용할 때마다 저장본을 덮어써서 꾸민 흔적이 남는 실패 경로와, 맨 처음 상태를 한 번만 따로 보관해 정확히 되돌리는 해결 경로 | https://yohanstudio.co/images/blog/usagi-windows-gift-set/pristine-backup-flow.png]

고친 방법은 단순했다. 맨 처음 상태를 딱 한 번만 따로 보관하고, 그 다음부터는 절대 건드리지 않게 했다.

## ✅ 되돌렸을 때 아무것도 안 남아야 끝이다

그 뒤로는 적용해보는 것보다 되돌려보는 걸 더 많이 했다.

아래는 같은 화면을 두 번 찍은 거다. 왼쪽은 우사기를 적용한 상태, 오른쪽은 전체 원복을 누른 뒤다. 폴더도 휴지통도 커서도 원래 윈도우로 돌아왔고, 설정이나 남은 파일도 없다.

[이미지 삽입: 우사기를 적용한 화면과 전체 원복한 화면 대조 | https://yohanstudio.co/images/blog/usagi-windows-gift-set/apply-restore.png]

커서는 화면 캡처에 안 찍혀서, 그때 적용돼 있던 커서 파일을 같은 자리에 겹쳐 표시했다.

[여기 네 말: 원복을 눌렀는데 우사기가 그대로 있는 걸 처음 봤을 때 심정 한두 문장]

## 🛡️ 파일은 공개하지 않는다

이건 친구한테 준 개인 선물이다. 우사기 이미지랑 커서·아이콘 파일, 설치 파일, 저장소는 공개하지 않는다.

내가 개인적으로 만들어 쓴 것과, 아무나 받아갈 수 있게 올려두는 건 다른 문제라고 생각해서다. 그래서 화면으로 보여주는 것까지만 하고, 받아갈 수 있는 링크는 만들지 않았다.

언젠가 공개한다면 우사기 세트가 아니라, 각자 원하는 그림을 넣어서 자기 윈도우 테마를 만드는 도구가 될 것 같다. 물론 되돌리기 버튼은 제대로 만들어서.

릴스에서 본 건 커서 하나였다. 만들고 나니 선물의 완성은 커서가 움직이는 순간이 아니었다. 친구가 마음이 바뀌었을 때 원래대로 돌아갈 수 있는 순간이었다.

개발자가 아닌 사람이 AI와 함께 만드는 과정을 기록하고 있습니다.
