카테고리: build
증상: 페이지 HTML은 200이지만 _next/static 청크가 500을 반환하고 브라우저 콘솔 QA가 실패한다.
원인: 실행 중인 next dev와 next build가 같은 .next 폴더를 번갈아 갱신해 HTML의 청크 해시와 실제 파일이 어긋난다.
해결: 해당 프로젝트의 개발 서버를 종료한 뒤 개발 서버 또는 프로덕션 서버 한 종류만 깨끗하게 다시 실행하고 QA를 재시도한다.
적용조건: 동일한 워크트리에서 next dev가 실행 중인 상태로 next build 또는 .next 정리를 수행한 경우

# 확인 절차

1. 실패한 콘솔 메시지만 보지 말고 500 응답 URL을 함께 기록한다.
2. URL이 `/_next/static/chunks/`를 가리키면 포트를 점유한 프로세스가 현재 워크트리의 개발 서버인지 확인한다.
3. 정확한 PID만 종료하고 새 개발 서버를 시작한다.
4. 동일 QA를 재실행해 HTML 200, 정적 청크 200, 콘솔 오류 0을 함께 확인한다.

개별 청크를 복사하거나 콘솔 오류를 무시 목록에 추가하면 해시 불일치가 다시 나타나므로 해결책으로 사용하지 않는다.
