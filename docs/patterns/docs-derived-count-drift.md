# 파생 수치 문서 드리프트

- 패턴명: 파생 수치 문서 드리프트
- 카테고리: build
- 증상: README·로그·홍보 문구에 적힌 파일 수나 테스트 수가 현재 코드·산출물의 실제 개수와 다르다.
- 원인: 과거에 손으로 적은 숫자가 산출물 추가·삭제·테스트 매개변수 변경 뒤 자동으로 갱신되지 않는다.
- 해결: 발행 직전에 현재 Git 추적 산출물과 실제 테스트 실행 결과에서 수치를 다시 계산한다. 문서·표·파일 시스템의 숫자가 다르면 원인을 해결하기 전까지 제목과 핵심 주장에서는 숫자를 뺀다. 반복 사용하는 수치는 가능하면 빌드 스크립트가 생성하거나 검증하게 한다.
- 적용조건: 파일·에셋·테스트·장면·검증 항목처럼 코드나 산출물에서 파생된 개수를 문서·포트폴리오·릴리스 노트에 사용할 때.
