## 기록 규칙
- 새 항목은 표 하단에 append. ID는 `BL-{다음번호}`.
- Goal로 승격되면 지우지 말고 `상태`에 승격 대상을 적는다(추적 끊김 방지).
- 처리 완료 시 `상태` = `완료 (YYYY-MM-DD, PR #N)`.
