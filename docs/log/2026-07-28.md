## 교훈 (Dev Log 필드용)
1. **고치기 전에 재라** — 코드상 최악(canonical 오염)이 필드에선 피해 0이었고, 진짜 병목(콘텐츠)은 코드 밖이었다. 필드 데이터가 우선순위를 두 번 뒤집음.
2. **"발생원 못 찾음" ≠ "발생원 없음"** — `/$`·`/&` 를 href 스캔만으로 "과거 잔재"라 닫았다가 재조사에서 React 마커로 확정. 스캔 범위를 결론으로 승격시키지 말 것.
3. **가드는 되돌려서 빨간불을 봐야 실물** — semver 검사는 회귀 주입에도 통과했다(RSC payload). DoD의 "일부러 되돌려 확인"이 무용지물 가드를 걸렀다.
4. **무인 루프에 확정 티켓 주입 가능** — deferredPath 시드 + rationale에 명세 SoT·금지사항·검증 명령을 박으면 명세 준수율이 높다(5/5, 금지 파일 0 접촉).
