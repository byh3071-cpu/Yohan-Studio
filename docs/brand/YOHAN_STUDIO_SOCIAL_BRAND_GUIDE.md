# Yohan Studio SNS Brand Guide

> 로컬 Codex와 모든 AI 코딩 도구가 SNS·블로그·브랜드 작업에서 공통으로 따라야 할 단일 기준 문서(Single Source of Truth)

- 문서 버전: v1.0
- 기준일: 2026-08-03
- 적용 범위: Yohan Studio 웹사이트, 네이버 블로그, 티스토리, Instagram, YouTube, Threads, X, Reddit, 디스콰이엇, 긱뉴스 및 향후 추가 채널
- 상태 표기: `확정`은 그대로 적용하고, `검토 필요`는 사용자 확인 없이 임의로 확정하지 않는다.

## 1. 브랜드 핵심 정의

### 1.1 브랜드명 — 확정

- 공식 브랜드명: `Yohan Studio`
- 기본 표시 이름: `Yohan Studio`
- 기본 핸들: `@yohanstudio`
- 대표 도메인: `https://yohanstudio.co`
- 한글로 읽을 때: `요한 스튜디오`

`YOHAN STUDIO`를 기본 워드마크로 쓰던 이전 논의는 폐기한다. 현재 마스터 커버와 워드마크는 `Yohan Studio`로 표기하며, `Studio`의 소문자 `i` 위 점을 오렌지 시그니처로 사용한다.

### 1.2 현재 정체성 — 확정

> **AI로 제품과 작품을 만들고 세상에 내놓는 1인 스튜디오.**

Yohan Studio는 AI 정보를 단순히 모아 전달하는 채널이 아니다. AI를 실제 제작 도구로 사용해 제품·서비스와 음악·영상·영화·게임·예술 등의 창작물을 만들고, 실험하고, 공개하는 **AI-native 1인 제품·창작 스튜디오**다.

### 1.3 브랜드 구조 — 확정

| 구분 | 정의 | 외부 표현 방식 |
|---|---|---|
| 장기 비전 | AI를 활용해 운영되는 1인 유니콘 기업 | 아직 달성하지 않은 목표이므로 공식 소개에 직접 주장하지 않는다. |
| 현재 정체성 | AI-native 1인 제품·창작 스튜디오 | 모든 채널의 핵심 소개로 사용한다. |
| 만드는 것 | 제품·서비스·도구·자동화와 음악·영상·영화·게임·예술 | 채널과 콘텐츠에 맞게 구체화한다. |
| 콘텐츠 방식 | 실제 제작 과정, 실험, 결과, 실패와 배운 점을 기록 | 신뢰를 증명하는 방식으로 사용한다. |
| 브랜드 역할 | 여러 제품과 프로젝트를 만드는 상위 스튜디오 브랜드 | MOVA 등 개별 프로젝트는 Yohan Studio 아래에 둔다. |

### 1.4 브랜드가 주어야 할 인상 — 확정

우선순위는 다음 세 가지다.

1. 단단하고 신뢰할 수 있음
2. 감각적이고 세련됨
3. 쉽고 친근하게 이해됨

‘AI스럽게 보이는 것’ 자체는 목표가 아니다. 실제로 만드는 사람의 결과와 기록을 통해 신뢰받는 것이 목표다.

## 2. 핵심 문구 체계

### 2.1 마스터 한 문장 — 확정

> **AI로 제품과 작품을 만들고 세상에 내놓는 1인 스튜디오.**

### 2.2 공통 프로필 소개 — 확정

> AI로 제품과 작품을 만들고 세상에 내놓는 1인 스튜디오.  
> 개발·창작 과정과 실험 기록을 공유합니다.  
> ↓ 프로젝트와 전체 기록

플랫폼의 글자 수가 짧으면 아래 순서대로 줄인다.

- 중간형: `AI로 제품과 작품을 만드는 1인 스튜디오. 제작 과정과 실험을 기록합니다.`
- 짧은형: `AI로 제품과 작품을 만드는 1인 스튜디오.`

### 2.3 웹사이트·커버 슬로건 — 확정

> **AI로 만들고, 실험하고, 세상에 내놓습니다.**

웹사이트 Hero 보조 문구:

> 제품부터 음악·영상·게임까지, 새로운 가능성을 직접 만들고 검증합니다.

### 2.4 영문 소개 — 확정

> **An AI-native one-person studio building products and creative works.**

### 2.5 보조 문구 — 제한적 사용

> AI로 짓고, 코드로 굴리는 1인 스튜디오.

이 문구는 제품 개발·코딩·자동화 프로젝트에는 쓸 수 있지만 음악·영상·예술까지 포괄하지 못한다. Yohan Studio 전체 브랜드의 대표 문구로 사용하지 않는다.

## 3. 시각 아이덴티티

### 3.1 디자인 방향 — 확정

- 스타일: `Editorial × Soft Brutalism`
- 핵심 인상: 명확한 구조, 넓은 여백, 단단한 타이포그래피, 절제된 오렌지 포인트
- 원칙: 화려한 AI 광고보다 오래 사용할 수 있는 독립 스튜디오 브랜드처럼 보여야 한다.

### 3.2 색상 — 확정

| 역할 | 색상명 | HEX | 권장 비중·용도 |
|---|---|---:|---|
| 기본 배경 | Warm Cream | `#F4F1EA` | 약 70%, 배경 |
| 텍스트·구조 | Ink Black | `#0A0A0A` | 약 20%, 글자·선·테두리 |
| 시그니처 강조 | Signal Orange | `#FF5C28` | 10% 이하, CTA·핵심 포인트·`i` 점 |
| 보조 | Soft Gray | `#D8D3CA` | 구분선·보조 배경 |

금지:

- 흔한 AI 보라색·파란색 네온 그라데이션
- 과도한 오렌지 면적
- 불필요한 광택, 3D, 유리 효과
- 배경 질감·색 번짐이 들어간 마스터 에셋

### 3.3 폰트 — 확정

- 한국어 본문·UI: `Pretendard Variable`
- 영문 제목·숫자·강조: `Space Grotesk`
- 워드마크: 동일한 산세리프 계열 안에서 `Yohan`은 굵게, `Studio`는 상대적으로 가볍게
- 폰트 패밀리는 원칙적으로 두 개 이상 늘리지 않는다.

### 3.4 워드마크 — 확정

- 표기: `Yohan Studio`
- `Yohan`: 굵고 단단하게
- `Studio`: `Yohan`보다 가볍지만 모바일 축소에서도 흐려지지 않게
- `Studio`의 소문자 `i` 위 점만 완전한 원형의 `#FF5C28`
- 나머지 글자: `#0A0A0A`
- 오렌지 점 외의 장식은 기본적으로 추가하지 않는다.

### 3.5 프로필 이미지 — 확정

- 현재 확정한 검정 선화·크림 배경의 남성 얼굴 클로즈업 캐릭터를 모든 채널에서 동일하게 사용한다.
- 프로필은 ‘창업자/만드는 사람’을 보여주고, 커버는 ‘Yohan Studio 브랜드’를 보여준다.
- 이미지에 글자, 로고, 오렌지 요소를 추가하지 않는다.
- 원형 크롭에서 머리카락이 잘리는 플랫폼만 전체 이미지를 약 5% 축소해 크림색 여백을 확보한다.
- 새로운 프로필을 만들기 전에 기존 확정본을 우선 사용한다.

### 3.6 마스터 커버 — 방향 확정, 플랫폼 파생본 필요

- 16:9 가로형 마스터
- 배경: 완전한 단색 `#F4F1EA`
- 중앙 정렬, 넓은 여백
- 워드마크: `Yohan Studio`
- `Studio`의 `i` 점만 `#FF5C28`
- 슬로건: `AI로 만들고, 실험하고, 세상에 내놓습니다.`
- 사진·캐릭터·테두리·격자·장식선·그림자·입체감·그라데이션은 사용하지 않는다.
- 플랫폼마다 같은 파일을 억지로 늘이지 않고, 동일 디자인을 안전 영역에 맞춰 재배치한다.
- 네이버·YouTube·X 등 플랫폼별 최종 규격과 크롭본은 별도 제작이 필요하다.

## 4. 브랜드 말투(Voice & Tone)

### 4.1 기본 정의 — 확정

> **직접 만드는 사람이 결과와 근거를 바탕으로 쉽게 설명하는 말투**

### 4.2 작성 원칙

- 결론부터 말한다.
- 짧고 단단한 문장을 쓴다.
- 어려운 용어는 쉬운 한국어와 필요한 영어 용어를 함께 설명한다.
- 실제로 만든 것, 관찰한 것, 검증한 것을 중심으로 말한다.
- 사실, 추론, 가정을 구분한다.
- 실패·한계·미완성 상태를 숨기지 않는다.
- 과장된 성공담, AI 만능론, 근거 없는 미래 예측을 피한다.
- 현재 1인 스튜디오이므로 `저희`보다 `저는` 또는 `Yohan Studio는`을 쓴다.
- 지나친 전문가 행세보다 ‘만들면서 배우고 검증하는 제작자’의 위치를 유지한다.

좋은 예:

> AI에게 전부 맡기는 것이 답은 아니었습니다. 직접 만들어보니 먼저 정리해야 할 것은 프롬프트가 아니라 작업 구조였습니다.

피해야 할 예:

> AI 하나로 누구나 압도적인 성공과 혁신을 만들 수 있습니다.

## 5. 콘텐츠 체계

### 5.1 내부 콘텐츠 분류 — 확정

| 축 | 정의 | 예시 |
|---|---|---|
| `BUILD` | AI 제품·서비스·도구·자동화 제작 | MOVA, 에이전트, 업무 자동화, 웹·앱 제작 |
| `CREATE` | AI를 활용한 예술·창작 | 음악, 영상, 영화, 게임, 이미지, 실험 작품 |
| `LOG` | 제작 과정·실험·실패·배운 점 | 빌드 로그, 회고, 비교 테스트, 시행착오 |

이 세 이름은 우선 내부 분류다. 모든 게시물 제목에 억지로 노출하거나 해시태그로 강제하지 않는다.

### 5.2 콘텐츠 판단 기준

Yohan Studio에 올릴 콘텐츠는 아래 중 하나 이상을 충족해야 한다.

- 직접 만들었거나 실제로 사용해봤는가?
- 구체적인 결과·과정·데이터·화면을 보여줄 수 있는가?
- 다른 제작자가 적용할 수 있는 배움이 있는가?
- Yohan Studio의 제품·창작 방향과 연결되는가?

단순 AI 뉴스 요약은 핵심 콘텐츠가 아니다. 다룰 경우 반드시 ‘이 변화가 실제 제작과 Yohan 생태계에 어떤 영향을 주는가’를 추가한다.

### 5.3 원본과 파생 콘텐츠 구조 — 현재 운영 원칙

1. 하나의 프로젝트·실험에서 원본 기록을 만든다.
2. 원본은 MDX 기반의 장문 기록 또는 웹사이트 프로젝트 페이지로 관리한다.
3. 네이버 블로그·티스토리에는 검색과 독해에 맞는 장문으로 재구성한다.
4. Instagram에는 Reel·Carousel 등 시각 중심 콘텐츠로 압축한다.
5. Threads·X에는 핵심 생각, 과정, 진행 상황을 짧은 로그로 나눈다.
6. YouTube에는 제작 과정, 데모, 회고를 영상 자산으로 남긴다.
7. 커뮤니티에는 그 커뮤니티 안에서 먼저 가치가 완결되도록 작성하고, 관련 있을 때만 원문 링크를 덧붙인다.

복사·붙여넣기로 모든 채널에 동일한 글을 게시하지 않는다. 브랜드 약속은 같게 유지하고, 형식과 CTA만 플랫폼에 맞춘다.

## 6. 채널별 역할과 프로필 문구

### 6.1 공통 계정 설정 — 확정

- 표시 이름: `Yohan Studio`
- 핸들 1순위: `@yohanstudio`
- 프로필 이미지: 확정한 캐릭터 프로필
- 대표 링크: `https://yohanstudio.co`

### 6.2 웹사이트 — 브랜드 중심 허브

역할:

- Yohan Studio의 공식 정체성과 프로젝트를 보여주는 중심 허브
- 모든 SNS에서 돌아오는 대표 링크
- 제품·창작물·장문 기록의 정식 도착지

Hero:

> AI로 만들고, 실험하고, 세상에 내놓습니다.  
> 제품부터 음악·영상·게임까지, 새로운 가능성을 직접 만들고 검증합니다.

### 6.3 네이버 블로그 — 한국어 장문 기록·검색 채널

역할:

- 현재 운영 중인 핵심 블로그

- 한국어 검색 유입과 신뢰 축적

권장 설정:

- 블로그명: `Yohan Studio`
- 프로필명: `요한 | Yohan Studio`

- CTA: `전체 글과 프로젝트 → yohanstudio.co`

남은 작업:

### 6.4 티스토리 — 보조 장문·검색 채널

역할:

- 기술 글·프로젝트 기록의 검색 노출을 보완할 수 있는 채널
- 네이버 글의 무조건적인 복제 저장소로 운영하지 않는다.

권장 소개:

> AI로 제품과 작품을 만드는 1인 스튜디오. 개발·창작 과정과 실험 기록을 공유합니다.

CTA:

> 프로젝트와 전체 기록 → yohanstudio.co

운영 시작 시점과 네이버·웹사이트 사이의 원문 기준은 아직 검토 필요다.

### 6.5 Instagram — 신규 유입을 만드는 핵심 시각 채널

역할:

- Reel과 Carousel로 새로운 사람에게 도달
- 결과물, 전후 비교, 짧은 제작기, 실험 핵심을 시각적으로 전달
- Threads 및 웹사이트로 관심을 연결

권장 Bio:

> AI로 제품과 작품을 만드는 1인 스튜디오  
> 제작 과정과 실험 기록

### 7.1 계정 확보 순서

### 7.2 실제 콘텐츠 운영 우선순위 — 현재 권장안

## 10. 로컬 Codex 작업 규칙

SNS·브랜드 관련 작업을 맡을 때 다음을 따른다.

1. 이 문서를 현재 기준 문서로 읽는다.
2. `확정`된 문구·색상·표기를 임의로 바꾸지 않는다.
3. 기존 에셋이 있으면 새로 생성하기 전에 찾아서 재사용한다.
4. 플랫폼의 최신 이미지 규격·Bio 글자 수·핸들 정책은 실제 적용 직전에 공식 자료로 확인한다.
5. 채널별 형식과 CTA는 바꿀 수 있지만 브랜드의 정체성과 핵심 문장은 유지한다.
6. `Yohan Studio`를 AI 뉴스 큐레이션 채널로 축소해 정의하지 않는다.
7. ‘1인 유니콘 기업’을 이미 달성한 것처럼 외부 문구에 쓰지 않는다.
8. 계정 생성, 게시, 메시지 전송, 광고 집행 등 외부 행동은 사용자 승인 없이 실행하지 않는다.
9. 미확정 항목은 그럴듯하게 채우지 말고 `검토 필요`로 남기거나 질문한다.
10. 이 문서와 다른 오래된 문구가 충돌하면 이 문서의 v1.0 기준을 우선한다.
