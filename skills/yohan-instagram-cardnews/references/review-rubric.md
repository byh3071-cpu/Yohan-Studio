# 카드뉴스 검수 루브릭

각 항목을 `PASS`, `FAIL`, `실플랫폼 확인 필요` 중 하나로 판정한다. FAIL에는 카드 번호, 증상, 근거, 수정안을 함께 적는다.

## 1. 내용

- 표지가 독자가 얻을 결과를 한 번에 말한다.
- 모델·기능·설정·제품 이름을 서로 혼동하지 않는다.
- 명령어와 링크가 최신 공식 근거 또는 실제 실행 결과와 일치한다.
- 명령어의 짧은 플래그와 별칭을 실제 CLI `--help` 또는 원본 문서로 확인했다.
- 검증한 제품·플러그인 버전, 날짜, 출처가 생성 기록에 남아 있다.
- 카드가 없어도 캡션과 DM의 약속이 서로 일치한다.
- 출처·면책 문구가 핵심 정보를 밀어내지 않는다.

## 2. 모바일 가독성

- 540×675 축소본에서 제목과 명령어를 확대 없이 읽을 수 있다.
- 작은 배지·번호·보조 설명이 흐릿한 장식으로 남지 않는다.
- 얇은 글꼴과 낮은 대비가 핵심 정보에 사용되지 않는다.
- 긴 명령어가 글자 축소가 아니라 의미 단위 줄바꿈으로 해결됐다.
- 핵심 텍스트와 로고가 중앙 1080×1080 안전영역(세로 135~1215px) 안에 있다.
- 실제 인스타 편집 화면에서 흐림·잘림·UI 가림이 없다.

## 3. 정렬과 리듬

- 여러 줄 제목의 행간이 카드마다 일관된다.
- 번호 원은 첫 줄이 아니라 텍스트 블록 전체의 중심과 맞는다.
- 반복 패널의 좌우·상하 내부 여백이 같다.
- 카드 안의 요소가 한쪽으로 떠 있거나 불필요한 빈 공간을 만들지 않는다.
- 페이지 번호와 계정명이 안전 영역 안에서 같은 기준선에 놓인다.

## 4. 이미지 품질

- 원본 비율이 유지되고 찌그러짐이 없다.
- 텍스트 위에 이미지가 겹치거나 정보를 가리지 않는다.
- 생성 이미지 속 가짜 글자·로고·워터마크가 남지 않는다.
- 선명화가 과해 테두리 번짐이나 노이즈가 생기지 않는다.
- PNG가 1080×1350, RGB, 순차 파일명이다.

## 5. 자동화 안전

- 댓글 키워드와 공개 답변이 스팸처럼 보이지 않는다.
- 첫 DM은 사용자가 무엇을 받는지 설명하고 버튼 행동이 분명하다.
- 후속 DM에 약속한 정보·링크·주의사항이 모두 있다.
- 실제 게시물·트리거·테스트 계정을 확인했다.
- 사용자 승인 전 `Go Live` 또는 실제 발송을 실행하지 않았다.

## 6. 반복 학습

- 이번 수정이 주제 고유 문제인지 반복 가능한 문제인지 구분했다.
- 재사용 후보에는 최소 한 개의 실제 승인 근거가 있다.
- 전역 규칙 승격에는 서로 다른 게시물의 반복 근거와 사용자 승인이 있다.
- 거절된 디자인을 승인 패턴처럼 기록하지 않았다.

## 판정 형식

```text
판정: PASS | FAIL | 실플랫폼 확인 필요

- [심각도] 카드 04 — 번호 원이 두 줄 명령어보다 위에 있음
  근거: 50% 축소본에서 시각 중심 불일치
  수정: 번호 중심을 패널 중심 Y에 맞춤
```

치명·높음 결함이 하나라도 있으면 FAIL이다. 실플랫폼 확인이 남아 있으면 작업본으로만 전달하고 게시 승인으로 간주하지 않는다.
